# VERCTECH - RESULTADOS

Demonstração web de um projeto de portfólio de análise comercial de uma empresa fictícia de informática.

## Explorar

Abra o site publicado no GitHub Pages ou o arquivo index.html no navegador. Não há instalação de dependências, login ou servidor de aplicação.

- 15.000 pedidos simulados em 2024 e 2025, distribuídos pelas 27 UFs.
- Filtros por ano, mês, região, UF, canal e categoria.
- Faturamento, lucro bruto, pedidos distintos, margem ponderada e ticket médio.
- Visões de produtos, distribuição nacional, insights e exportação CSV.

## Ferramentas

Python para geração e validação; SQLite e SQL para consultas; Power BI, Power Query e DAX no relatório original. Esta demonstração independente utiliza HTML, CSS e JavaScript, com gráficos SVG. Não é uma incorporação do Power BI.

## Limites

Empresa e dados são fictícios, criados para estudos. Faturamento corresponde a vendas concluídas após descontos, sem tributos ou devoluções. Lucro bruto desconta somente custos dos produtos; não é lucro líquido. Os resultados não são estimativas do mercado real.

A base está embutida no index.html e será pública junto da página. Não utilize dados pessoais ou confidenciais nesta estrutura.
